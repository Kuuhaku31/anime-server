# 前端 UI 设计

支持桌面布局和移动端触控, iPhone 与 iPad 使用可保留画面弹幕的页内全屏.

分成左右两部分
左侧是视频播放交互区域
提供简单视频控制和下方独立滚动的弹幕列表

右侧分成上下两部分, 两个列表
上部分是 媒体文件表, 以媒体文件在容器中地址为主键
下部分是 缓存文件夹表, 以handle_id为主键

两个列表独立滚动, 默认仅显示关键信息, 点击展开显示全部信息.
展开箭头使用固定窄列, 文件名过长时截断并提供完整路径提示, 详情中的路径和诊断可换行.

## 媒体文件表

摘要显示文件名, 观看进度和已保存的 episode ID, 已加载 metadata 时还显示时长和格式.
列表接口只返回文件 ID, 路径, 播放配置和可空 episode_id, 展开时按需请求 metadata.

展开后显示:
- 各项状态
- 支持的视频/音频/字幕流的选项框
- 根据此配置创建缓存文件夹按钮
- 单文件重扫和 metadata 失败时的显式重试入口
- DandanPlay episode ID 输入框, Save ID 和 Identify 按钮

剧集编辑区不依赖 metadata 成功, 输入正整数后点击 Save ID 保存,
清空后保存会将关联设为 NULL. 播放进度和轨道偏好保持不变.
已有 ID 时仍可点击 Identify, 不必清空或保存后再重新识别.
识别只发送路径给后端, 后端向 DandanPlay 提交文件名, MD5 和大小, 不上传视频.

精确且唯一的结果覆盖已有 ID 并填入输入框, 不再显示候选列表或候选选择按钮.
无唯一匹配时保留原 ID 并显示对应提示, 原 ID 为空时提示手动填写.
界面使用响应 matched 标志判断本次结果, 非空 episode_id 也可能只是保留的原关联.
请求失败保留原 ID, 只在当前内容的编辑区显示诊断, 不阻塞播放或其他媒体项.
同内容副本共享 ID 和在途状态, 保存和识别期间禁用这些副本的重复操作.
输入草稿和焦点在 metadata 更新及播放高亮重绘后保留.
输入框和按钮可换行, 结果和错误使用纯文本并允许长文字换行.
修改当前播放媒体的关联会立即同步弹幕区域, 但不会自动加载弹幕.

## 弹幕列表

播放器下方显示当前路径已保存的 DandanPlay episode ID,
Load comments 和 Refresh comments 都在该区域内.
没有当前媒体或没有关联 ID 时禁用两个按钮并显示提示.
普通加载优先使用文件缓存, 刷新发送 refresh=true, 请求进行中禁用重复操作.
不显示缓存来源或 `cached` 字段, 不自动加载, 不在浏览器持久化弹幕.

切换播放路径或当前关联 ID 时清空旧列表, 错误和等待状态, 取消旧请求并等待手动加载.
即使两条媒体使用同一 episode ID, 切换路径后也要重新点击加载.
加载成功替换完整列表, 首次失败显示局部诊断, 刷新失败保留已显示内容.
合法空结果显示无弹幕提示, 协议错误不会显示成成功的空列表.
保存和识别使用 Library 的 change 通知更新当前 ID, 不干扰播放控制器.

按时间升序显示完整条目, 内容在左侧为主要元素, 右侧时间精确到百分之一秒,
超出百分秒安全整数范围的极大时间保留原始秒数, 不显示溢出的时间标签.
模式名称和原始编号, 十六进制 RGB 与色块, sender 和 cid 位于次要信息行.
内容使用纯文本并保留换行, 长内容和标识允许断行, 不与时间列重叠.
未知模式保留数字, cid 使用字符串避免大整数舍入.

随播放高亮最近一条 `time <= 播放位置 + 时间偏移` 的弹幕, 同时间组定位最后一条.
只有索引改变才更新高亮和滚动, 不在每次 timeupdate 重绘整表.
seek 无论向前或向后都会立即重新定位, 首条之前取消高亮并回到列表顶部.
只滚动弹幕容器, 不滚动页面或媒体及缓存列表, 暂停时可手动浏览.
面板高度有界, 视频仍保持最小高度; 小屏压缩视频和弹幕占位, 给文件列表保留操作空间.
全屏隐藏列表, 退出或尺寸改变时恢复当前定位.
不包含弹幕过滤, 发送或登录.

## 画面弹幕和设置

Canvas 与下方列表共享一次手动加载的原始数组, Load 或 Refresh 成功后同时替换,
刷新失败保留两者, 媒体或关联切换同时清空. 不新增自动加载或第二份请求.
mode 1 和未知模式从右向左滚动, mode 5 顶部固定, mode 4 底部固定.
滚动持续时间按画面宽度缩放到 4..9 秒, 固定弹幕显示 3.8 秒.
按 RGB 着色, 近黑文字使用白描边, 其他文字使用黑描边, 填充与描边共用透明度.
Canvas 仅覆盖真实视频内容, 保持黑边干净并按 DPR 绘制, 不阻断单击和双击.

轨道优先避免重叠, 滚动检查入口间距及速度差追尾, 固定弹幕占用整段显示时间.
三种模式共用轨道. 没有安全轨道时复用最早可用轨道, 不提供密度或重叠选项.
暂停和 buffering 冻结当前位置, seek, 重新加载和尺寸变化立即按新时间窗重建.
画面文字折叠换行和控制空白, 下方列表保留原始内容及无障碍阅读入口.

播放器控件提供画面弹幕开关和 Comment settings 按钮, 普通和全屏模式均可用.
设置表单默认启用, 字号 28px, 描边 1.5px, 透明度 0.9, 滚动区域 75%, 偏移 0 秒.
字号支持 12..72, 描边支持 0..6, 透明度支持 0.1..1, 滚动区域支持 10..100%,
偏移支持 -120..120 秒. 数字必须有限, 空输入明确报错.
区域比例只限制顶部滚动轨道且最少一行, 顶部和底部固定弹幕不受比例限制.
正偏移使弹幕提前显示, 下方列表也使用相同偏移定位, 原始时间标签不改变.

输入只是草稿, Apply 应用到当前页面, Save 原子保存到服务端 config.json 并应用.
快捷开关也是当前页面预览, 需要 Save 才持久化. 设置不写入 localStorage.
保存期间禁用字段和快捷开关, 成功回填服务端响应, 失败保留草稿和当前预览并显示局部诊断.
其他页面下次刷新读取新值. 关闭弹层不丢弃草稿, Escape 优先关闭设置再退出全屏.
打开设置时全屏控件保持可见, 弹层高度受播放器限制并可独立滚动,
关闭入口固定在弹层顶部, 不随字段滚出小屏或软键盘缩小后的可见区域.

## 缓存文件夹表

折叠摘要显示文件名, 短 handle_id, 编码状态, worker 资源和编码进度条.
进度随缓存轮询实时更新, 使用 `buffered_until / duration` 计算, 与播放位置和浏览器缓冲无关.
源时长通过 Library 自动按需加载, 与媒体展开共用按内容 ID 去重的请求和内存缓存.
重扫使旧 metadata 失效, 在途旧响应不能覆盖新结果.

时长未知时显示不确定进度条和已生成绝对时间, 不显示虚假的百分比.
metadata 失败只影响时长展示, 保留局部诊断, 不自动循环请求或重试编码.
完成缓存始终显示 100%, 使用绿色背景, 边框和进度条.
当前播放项另有强调边框, 与完成状态可同时识别.

展开后显示:
- 各项状态
- 播放按钮
- 单个编码切换按钮
- 删除缓存文件夹按钮

| 阶段 | 编码切换按钮 | 行为 |
| --- | --- | --- |
| running | Pause encoding | 暂停编码, 保留已有缓存 |
| stopping | Pause encoding | 禁用, 等待暂停完成 |
| ready / failed | Retry / resume | 显式恢复或重试编码 |
| loading | Preparing... | 禁用 |
| completed | Completed | 禁用 |

请求进行中禁用对应缓存项的操作, 没有源文件时不能恢复或播放.
播放仅读取已有缓存资源, 不自动触发编码.
删除必须确认, 其余操作和页面关闭都不自动删除持久化缓存.
进度条只在摘要显示, 展开详情不重复显示.

## 播放器

普通模式保留完整控件, 状态和错误反馈.
全屏和页内全屏使用黑色视频背景, 视频等比完整显示, 底部渐变悬浮控件不挤压视频高度.
全屏保留文件名, 播放/暂停, 进度, 时间, 音量, 弹幕开关, 设置和退出全屏,
隐藏 Stop, Start over, 普通状态区和弹幕列表, 不隐藏 Canvas.

播放时约 3 秒无操作自动隐藏全屏控件和光标, 鼠标移动或键盘操作重新显示.
暂停, 拖动进度, 控件悬停, 键盘焦点位于控件内, 设置展开, 操作等待或播放错误时保持显示.
播放出错时恢复可见的错误反馈和恢复入口, 不因全屏而隐藏诊断.
普通页面的控件不自动隐藏.

单击视频播放/暂停, 双击切换全屏, 双击不会额外触发单击播放操作.
Space / K 控制播放, 左右方向键跳转 10 秒, M 静音, F 切换全屏.
表单控件保留自身快捷键, Escape 在控件聚焦时也能退出页内全屏.
退出全屏和离开页面时清理隐藏计时器, 光标状态及页内全屏滚动锁.

桌面和 Android 优先请求整个 player-panel 元素全屏, 拒绝时回退 expanded 页内全屏.
iPhone, iPad 和桌面 UA 的触控 iPad 强制使用页内全屏, 保留 playsinline,
不调用无法显示网页 Canvas 的系统视频全屏. 页内全屏不保证隐藏地址栏或锁定方向.
visible viewport, 横竖屏和 safe-area 变化同步布局, 刘海和底部手势区不遮挡退出控件.
