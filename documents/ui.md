# 前端 UI 设计

**目前只优先考虑pc端浏览器适配**

分成左右两部分
左侧是视频播放交互区域
仅负责简单视频控制

右侧分成上下两部分, 两个列表
上部分是 媒体文件表, 以媒体文件在容器中地址为主键
下部分是 缓存文件夹表, 以handle_id为主键

两个列表独立滚动, 默认仅显示关键信息, 点击展开显示全部信息.
展开箭头使用固定窄列, 文件名过长时截断并提供完整路径提示, 详情中的路径和诊断可换行.

## 媒体文件表

摘要显示文件名, 观看进度和已保存的 episode ID, 已加载 metadata 时还显示时长和格式.
列表接口只返回文件 ID, 路径, 播放配置和可空 episode_id, 展开时按需请求 metadata.

展开后显示:
- 各项状态
- 支持的视频/音频/字幕流的选项框
- 根据此配置创建缓存文件夹按钮
- 单文件重扫和 metadata 失败时的显式重试入口
- DandanPlay episode ID 输入框, Save ID 和 Identify 按钮

剧集编辑区不依赖 metadata 成功, 输入正整数后点击 Save ID 保存,
清空后保存会将关联设为 NULL. 播放进度和轨道偏好保持不变.
已有 ID 时仍可点击 Identify, 不必清空或保存后再重新识别.
识别只发送路径给后端, 后端向 DandanPlay 提交文件名, MD5 和大小, 不上传视频.

精确且唯一的结果覆盖已有 ID 并填入输入框, 不再显示候选列表或候选选择按钮.
无唯一匹配时保留原 ID 并显示对应提示, 原 ID 为空时提示手动填写.
界面使用响应 matched 标志判断本次结果, 非空 episode_id 也可能只是保留的原关联.
请求失败保留原 ID, 只在当前内容的编辑区显示诊断, 不阻塞播放或其他媒体项.
同内容副本共享 ID 和在途状态, 保存和识别期间禁用这些副本的重复操作.
输入草稿和焦点在 metadata 更新及播放高亮重绘后保留.
输入框和按钮可换行, 结果和错误使用纯文本并允许长文字换行.
当前不包含弹幕下载或播放器弹幕层.

## 缓存文件夹表

折叠摘要显示文件名, 短 handle_id, 编码状态, worker 资源和编码进度条.
进度随缓存轮询实时更新, 使用 `buffered_until / duration` 计算, 与播放位置和浏览器缓冲无关.
源时长通过 Library 自动按需加载, 与媒体展开共用按内容 ID 去重的请求和内存缓存.
重扫使旧 metadata 失效, 在途旧响应不能覆盖新结果.

时长未知时显示不确定进度条和已生成绝对时间, 不显示虚假的百分比.
metadata 失败只影响时长展示, 保留局部诊断, 不自动循环请求或重试编码.
完成缓存始终显示 100%, 使用绿色背景, 边框和进度条.
当前播放项另有强调边框, 与完成状态可同时识别.

展开后显示:
- 各项状态
- 播放按钮
- 单个编码切换按钮
- 删除缓存文件夹按钮

| 阶段 | 编码切换按钮 | 行为 |
| --- | --- | --- |
| running | Pause encoding | 暂停编码, 保留已有缓存 |
| stopping | Pause encoding | 禁用, 等待暂停完成 |
| ready / failed | Retry / resume | 显式恢复或重试编码 |
| loading | Preparing... | 禁用 |
| completed | Completed | 禁用 |

请求进行中禁用对应缓存项的操作, 没有源文件时不能恢复或播放.
播放仅读取已有缓存资源, 不自动触发编码.
删除必须确认, 其余操作和页面关闭都不自动删除持久化缓存.
进度条只在摘要显示, 展开详情不重复显示.

## 播放器

普通模式保留完整控件, 状态和错误反馈.
全屏和页内全屏使用黑色视频背景, 视频等比完整显示, 底部渐变悬浮控件不挤压视频高度.
全屏仅保留文件名, 播放/暂停, 进度, 时间, 音量和退出全屏, 隐藏 Stop, Start over 和普通状态区.

播放时约 3 秒无操作自动隐藏全屏控件和光标, 鼠标移动或键盘操作重新显示.
暂停, 拖动进度, 控件悬停, 键盘焦点位于控件内, 操作等待或播放错误时保持显示.
播放出错时恢复可见的错误反馈和恢复入口, 不因全屏而隐藏诊断.
普通页面的控件不自动隐藏.

单击视频播放/暂停, 双击切换全屏, 双击不会额外触发单击播放操作.
Space / K 控制播放, 左右方向键跳转 10 秒, M 静音, F 切换全屏.
表单控件保留自身快捷键, Escape 在控件聚焦时也能退出页内全屏.
退出全屏和离开页面时清理隐藏计时器, 光标状态及页内全屏滚动锁.
